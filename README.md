# 🛒 Grocery App UI

A modern and user-friendly **Grocery App UI built with Flutter**, designed to provide a smooth and convenient online grocery shopping experience. This project focuses on clean UI design, product browsing, categories, and responsive layouts.

## ✨ Features

* 🏠 Home Dashboard
* 🥦 Grocery Categories
* 🔍 Product Search
* 🛍️ Product Listing
* 📦 Product Details
* 🛒 Shopping Cart
* ❤️ Wishlist
* 💳 Checkout UI
* 📍 Delivery Address
* 🚚 Order Tracking UI
* 📋 Order History
* 👤 User Profile
* 🔔 Notifications
* 📱 Responsive Design
* 🎨 Clean & Modern UI

## 🚀 Getting Started

### Prerequisites

Make sure you have:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* Android Emulator or Physical Device

### Installation

Clone the repository:

```bash
git clone https://github.com/your-username/grocery-app-ui.git
```

Navigate to the project:

```bash
cd grocery-app-ui
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
